Getting Started

Clone the repository and open index.html in your browser — or deploy straight to Replit.

bash 
# Clone the repo
git clone https://github.com/your-username/your-repo.git
cd your-repo

# Open locally (no build step needed)
open index.html

To customise the 3D scene, edit assets/js/scene.js. Some things you can change:

scene.js 
// Change geometry type
const geo = new THREE.IcosahedronGeometry(1, 0);

// Change colour palette
const colors = ['#667eea', '#764ba2', '#f093fb'];

// Change particle count
const COUNT = 60;
